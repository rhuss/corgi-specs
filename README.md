# corgi-specs

Spec artifacts for the corgi fork, kept outside the corgi repo so they never land in upstream PRs.
Written by the spex-detach extension (`archive.path` in corgi's `.specify/extensions/spex-detach/spex-detach-config.yml`).

- `brainstorm/`: brainstorm documents and their overview, written here directly by `/speckit-spex-brainstorm`
- `corgi/<feature>/`: specs archived by `/speckit-spex-finish`
